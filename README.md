# Research Code

Most of my current research code is maintained privately while papers and related projects are under active development. My work focuses on machine learning, large language models, adversarial robustness, privacy-preserving NLP, model evaluation, model fusion, and applied AI for sensitive domains.

My current research interests include:

- Large language model evaluation and robustness
- Adversarial machine learning for domain-specific NLP systems
- Model fusion and generative model reliability
- Privacy-preserving NLP and sensitive information detection
- Trustworthy AI for legal, biomedical, and other high-impact domains
- Applied machine learning workflows that connect research ideas with usable systems

Public repositories will be added as projects are cleaned for release, documentation is prepared, and publication-related constraints allow.
